# Microcontrollers University Course

Репозиторий содержит лабораторные и практические работы по микроконтроллерам и проектированию цифровых устройств на VHDL.

## Лабораторные работы MC

- Контроль температуры с использованием датчика, нагревателей, вентилятора и интерфейса USART.
- Работа с символьным экраном и матричной клавиатурой: ввод и проверка пароля с обменом данными по UART.

## Лабораторные работы FPGA

- Минимизация булевых функций с помощью карт Карно и реализация логических схем на VHDL.
- Разработка четырёхвходового мультиплексора с разрешающим входом на VHDL.
- Разработка реверсивного 8-разрядного двоичного счётчика с задаваемым модулем на VHDL.# Microcontrollers University Course
